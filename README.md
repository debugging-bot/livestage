# LiveStage 🎸

> 밴드를 위한 홍대 공연장 대관 플랫폼 — 검색부터 비교, 예약까지 한 사이트에서

**팀명:** NEXUS (5인) · **과목:** 웹프레임워크 (React) 팀 프로젝트

> ⚠️ 공연장 정보와 대관료는 수업용 **참고용 더미 데이터**이며 실제 정보가 아닙니다.

---

## 📌 프로젝트 소개

밴드가 공연장을 구할 때는 정보가 여러 곳에 흩어져 있고, 날짜별 예약 가능 여부를 알기 어렵고, 평일과 주말 대관료를 비교하기도 힘듭니다.
LiveStage는 **검색 → 비교 → 예약**을 한 사이트에서 할 수 있게 만드는 React 웹 프로젝트입니다.

## ✨ 주요 기능

| 화면 | 설명 |
|---|---|
| 메인 | 지역·날짜·인원·예산으로 검색, 인기 공연장 보기 |
| 검색 결과 | 종류 필터, 정렬 5가지, 예약 가능/마감 표시 |
| 지도 검색 | 지도 위 핀을 눌러 공연장 팝업 확인 후 상세로 이동 |
| 공연장 상세 | 사진과 정보·대관·장비·후기 탭 |
| 달력 | 2026.10 ~ 2027.01, 예약 가능(초록) / 마감(빨강) |
| 예약 4단계 | 날짜·시간 → 정보 입력 → 확인 → 완료 |
| 마이페이지 | 예약 내역(전체/예정/지난), 취소, 찜한 공연장 |

평일/주말 대관료가 다르게 자동 계산됩니다.

## 🛠 사용 기술

- **React** (JSX, 함수 컴포넌트, props, `useState`, `map`/`filter`)
- **Node.js** · **npm** — 실행 환경과 라이브러리 관리
- **Git** · **GitHub** — 브랜치로 나누어 협업
- 아직 수업에서 배우지 않은 기능(화면 이동 등)은 진도에 맞춰 적용 예정

## 🚀 시작하기

### 1. 준비물
- [Node.js](https://nodejs.org) **LTS** (24 권장, 22 이상이면 동작)
- [Git](https://git-scm.com)
- VS Code (권장)

```bash
node -v
git --version
```

### 2. 내려받아 실행

```bash
git clone https://github.com/debugging-bot/livestage.git
cd livestage
npm install
npm run dev
```

터미널에 `Local: http://localhost:5173/` 주소가 나오면 브라우저에서 엽니다. 종료는 `Ctrl + C`.

> `npm install`은 저장소를 새로 받을 때 한 번 해야 합니다.

## 🌿 협업 규칙 (Git)

- `main` 브랜치에 **직접 push 하지 않습니다.** `main`에는 항상 동작하는 코드만 둡니다.
- 각자 `feature/이름` 브랜치에서 작업하고 `dev`로 Pull Request 합니다. (예: `feature/data`, `feature/detail`)
- 합치기 전에 `npm run build`가 오류 없이 끝나는지 확인합니다.
- `node_modules/`, `dist/`는 `.gitignore`로 올리지 않습니다.
- 커밋 메시지는 "무엇을 왜"를 한 줄로 씁니다. 예: `검색 결과에 예산 필터 추가`

매일 작업 순서:

```bash
git checkout dev
git pull origin dev              # 하루 시작할 때 항상 먼저
git checkout -b feature/이름     # 브랜치를 처음 만들 때만
# ... 작업 ...
git add .
git commit -m "무엇을 왜"
git push -u origin feature/이름
```

그다음 GitHub에서 **Compare & pull request**를 눌러 base를 `dev`로 정하고, 조원 2가 확인한 뒤 Merge 합니다.
